# بنية KOSIF Audit Studio

## هدف المنتج

النظام مساحة تشغيل لملف المراجعة، لا أرشيف ملفات. الصفحة الأولى تجيب دائمًا عن: ما الإجراء التالي؟ ما البوابة المغلقة؟ ما الدليل الناقص؟ وما القرار الذي ينتظر إنسانًا؟

## الحدود

| الحد | المسؤولية | ما لا يفعله |
|---|---|---|
| النواة الحتمية | الاستيراد، التصنيف، القوائم، النسب، الاختبارات والعينة | لا تصدر رأيًا مهنيًا |
| برنامج المراجعة | A01–A10، 26 بوابة، النواقص والإجراء التالي | لا يفتح بوابة بشرية آليًا |
| مجلس المراجعين | ملاحظات مبنية على أرقام المحرك مع معيار وإجراء وحدود | لا يعدّل رقمًا أو تصنيفًا |
| سجل المعايير | الإصدار المثبت، الفقرات، السريان، المصدر وآخر تحقق | لا يغيّر ارتباطًا قائمًا بأثر رجعي |
| مساحة العمل | الطلبات، الأدلة، المخاطر، القرارات والإسناد | لا يعتبر الرفع وحده دليلًا كافيًا |
| التقرير | جاهزية ولقطة قابلة لإعادة الإنتاج | لا يقبل اختيار نوع الرأي يدويًا |

## برنامج الجولات

1. A01 — قبول الارتباط والاستقلال.
2. A02 — فهم المنشأة والبيئة.
3. A03 — الأهمية النسبية.
4. A04 — تقييم المخاطر.
5. A05 — الضوابط والاختبارات.
6. A06 — الإجراءات الجوهرية.
7. A07 — التقديرات والأحكام.
8. A08 — الاستمرارية والأحداث اللاحقة.
9. A09 — الإكمال والتحريفات.
10. A10 — التقرير ومراجعة الجودة.

كل بوابة تحمل `status` و`reason` و`missing[]` و`humanOnly`. عند فشل بوابة الاعتماد الحسابية تنتشر حالة المنع إلى الجولات التابعة وبوابة الرأي المشتق.

## اشتقاق الرأي

لا يمثل الإصدار الحالي نوع رأي نهائيًا لأن تقييمات التحريف والانتشار وقيد النطاق لم تُغلق. تصميم الإنتاج يشتق النوع من مدخلات منظمة معتمدة:

- تحريف مادي منتشر: رأي معارض.
- تحريف مادي غير منتشر: رأي متحفظ بسبب تحريف.
- قيد نطاق مادي منتشر: امتناع.
- قيد نطاق مادي غير منتشر: رأي متحفظ بسبب النطاق.
- لا سبب للتعديل: غير معدل.

تغيير النتيجة يتم بتغيير مدخلاتها المعتمدة، لا بتحرير نص الرأي.

## المعايير والتحديث

كل سجل معيار يعرض الجهة، الفقرات، الإصدار، وصف السريان، المصدر الرسمي، تاريخ آخر تحقق، وحالة التثبيت. في النسخة الخادمة القادمة تصبح دورة التحديث: اكتشاف → تحقق → اعتماد → تفعيل، مع تثبيت `release_id` لكل ارتباط وعدم التحديث بأثر رجعي.

## طريق الإنتاج متعدد المستخدمين

الخطوة التالية ليست إضافة شاشة أخرى، بل نقل الحالة إلى مخزن خادمي مع عزل المنشآت والارتباطات، RBAC، سجل أحداث append-only، بصمات الأدلة، موصل AI خادمي، وتحديث معايير محكوم. يبقى هذا الحد منفصلًا عن النواة الحتمية لتظل الحسابات قابلة لإعادة الإنتاج.
