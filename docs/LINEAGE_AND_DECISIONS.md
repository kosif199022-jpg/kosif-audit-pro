# سجل الانتقاء والقرارات

راجعت النسخة الموحدة المستودعات والأسطح المتاحة ضمن عائلة KOSIF، ثم أعادت تنفيذ أفضل الأفكار داخل حدود واضحة بدل جمع الإصدارات في طبقات متوازية.

| المصدر | ما استفدنا منه | ما لم نأخذه |
|---|---|---|
| `mahmoud1990` وcommit `767d1d1` | نواة BigInt، خط المعالجة، الإسناد، RTL والحركة المخفضة | الاستمرار بعد ميزان غير متوازن، تحويل المال إلى Number، التخزين العام الخام |
| `kosif-audit-studio` | مفهوم مساحة العمل والجولات وPBC وبوابات التقرير | تكرار الأسطح والإصدارات داخل المنتج |
| `sky` | الفصل المعماري، دورة المهمة، المصالحة وإغلاق الأدلة | نقل بنية خادم غير مكتملة إلى عرض محلي |
| `smart-trial-balance-review` | فكرة الجولات التكيفية وربط المعايير | مفتاح نموذج في localStorage، إرسال مباشر من المتصفح، رأي تلقائي |
| `Acc` | سجل القدرات والتحقق قبل النشر | الادعاءات غير المثبتة والتوجيه العكسي بين الإصدارات |
| `aurora-finance` و`moon` | إشارات بصرية وتقديم التحليل | الحسابات التركيبية وMoney عبر Number |
| `mafateeh-al-tharwa` | معرفة سياقية تساعد صياغة التفسير | تحويل المنتج إلى مكتبة أو أرشيف قراءة |
| `kosif-audit-pro@5555dc2` | عشر جولات، 26 بوابة، nextAction، مجلس حتمي، وعقود ألوان | الرأي اليدوي، مفتاح LLM في المتصفح، وفهرس معايير غير مثبت بالإصدارات |

## قرارات لا رجعة فيها داخل هذا الخط

- مصدر منتج واحد بدل أسماء vXX متوازية.
- بوابة الاعتماد `fail-closed` قبل أي قائمة أو تقرير.
- الرأي مشتق فقط، واعتماد الإصدار بشري مسمى.
- AI سردي واستشاري؛ الرقم من المحرك الحتمي.
- المعايير مثبتة على الارتباط مع مصدر رسمي وآخر تحقق.
- اللون أداة دلالية مختبرة، لا زينة تغطي ضعف سير العمل.

## الأسطح المنشورة المرجعية

سُجلت روابط v2 وv3 وAudit Council وAudit Studio وAccounting v3 والمسار القديم `/audit/` أثناء الجرد. لم تستجب أسطح Workers القديمة لجلسة الفحص الحالية، لذلك لم نعامل أوصافها التاريخية كدليل حي. الرابط الرسمي الوحيد للنسخة الموحدة هو رابط Site المذكور في طلب الدمج؛ تبقى الروابط الأخرى مراجع تاريخية إلى أن تُغلق أو تُحوّل إليه صراحة.
