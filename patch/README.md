# رقعة v17 — الطباعة والكثافة لـ kosif-stable

طبقة عرض بحتة فوق التطبيق الحيّ على `kosif-stable.kosif199022.workers.dev`.
**لا تغيّر أي قدرة**: لا منطق ولا معالج حدث ولا عنصر مخفي — أحجام ومسافات وتدفّق فقط.

## ما الأساس بالضبط

الصفحة الحيّة تُبنى من:

```
Acc/frontend/original-app-payload.gz   (مضغوطة في KV عبر 9 مفاتيح tamhees_v6_gz_b64_*)
  └─ = Acc/frontend/index.html         332,126 بايت — تحقّقت أنهما متطابقان بالمجموع
+ حقن Acc/frontend/kosif-v16.css/.js   عبر injectKosifV16
```

## عيب مكتشَف في الإنتاج

`injectKosifV16` يستعمل `lastIndexOf('</head>')`. والملف يحوي وسمَي `</head>`:

| الموضع | ماذا |
|---|---|
| 36901 | رأس الصفحة الحقيقي |
| 274995 | **داخل نص JavaScript** يبني مستند تقرير للطباعة |

فالحقن يصيب الثاني دائمًا، أي أن **أنماط v16 لم تصل إلى الصفحة قط** — تُدرَج
داخل سلسلة نصية. تحقّقتُ بفحص DOM: الوسم `kosif-v16-css` غير موجود في الصفحة.

`enhancement-module.fixed.js` يصلح ذلك: أول `</head>` للرأس، وآخر `</body>` للنهاية
(الثاني كان صحيحًا أصلًا).

كانت مخفية خلف تمرير أفقي صامت، وفي RTL يكون الفائض على اليسار حيث لا تتوقعه العين.

## التطبيق

يحتاج بيانات اعتماد Cloudflare (لا أملكها).

```bash
# ١) ارفع الطبقة إلى KV
wrangler kv key put --binding=DATA kosif_enhancements_v17_css --path kosif-v17.css

# ٢) استبدل وحدة الحقن في kosif-stable
cp enhancement-module.fixed.js Acc/workers/kosif-stable/modules/enhancement-module.js

# ٣) أضف سطر حقن v17 بعد سطر v16 في injectKosifV16، أو حمّلها من /kosif-v17.css

# ٤) انشر
wrangler deploy
```

بدون خطوة (٢) لن تظهر v16 **ولا** v17، لأن موضع الحقن خاطئ أصلًا.
